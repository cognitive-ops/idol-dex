# Idol Dex

Collection of RAG-powered applications for Japanese content.

## Apps

- **jav-chatbot** ([apps/jav-chatbot/](apps/jav-chatbot/)) — JAV information retrieval chatbot. Scrapes metadata from r18.com, javlibrary, dmm.co.jp. Users query via Claude with FAISS semantic search + RAG context.

## Setup

Each app has its own `requirements.txt` and `.env.example`. See individual READMEs for setup.
